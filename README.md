# mvp-b3-databricks
MVP desenvolvido para conclusão da Sprint de Engenharia de Dados da Pós Graduação em Ciência de Dados e Analytics da PUC-Rio. Esse projeto tem a finalidade exclusivamente acadêmica e educacional. O objetivo desse MVP é construir um pipeline de dados na nuvem que transforme dados públicos de negociação da B3 em informações organizadas.
